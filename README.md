## Overview

This repository contains the ROS 2 software stack developed by the
**RobotX PUCP Team** for the **Maritime RobotX Challenge 2026**.

The project integrates three robotic platforms:

| Platform | Vehicle | Role | Status |
|---|---|---|---|
| **USV** | Blue Robotics BlueBoat | Autonomous surface vehicle | In development |
| **UUV** | Blue Robotics BlueROV2 Heavy | Underwater inspection and autonomous missions | Real + simulation |
| **UAV** | To be determined | Aerial robotic platform | Platform selection |

The repository includes hardware interfaces, perception, control,
teleoperation, simulation, safety systems and mission-oriented autonomy.

## Robotic Platforms

### USV — BlueBoat

The surface platform is based on the **Blue Robotics BlueBoat**.

Current software development includes:

- Motion and navigation control
- Hardware interfaces
- Teleoperation
- Perception
- Beacon and safety systems
- Mission autonomy
