# Parámetros ArduSub de referencia

`ardusub_20260924.parm` es una captura del vehículo utilizada durante las
pruebas de control GUIDED, DVL y telemetría del 24 de septiembre de 2026.

Es una referencia reproducible y específica del vehículo. No debe cargarse
completa en otro ROV sin revisar orientación, sensores, EKF, actuadores,
failsafes y calibraciones.
